# 小说项目

本项目使用 `novel-control-station` 作为长篇控制中枢。项目根目录即控制面。

## 文件系统

- `00-project-overview.md` 项目总览与核心承诺
- `01-theme-and-proposition.md` 主题与命题
- `02-worldbuilding.md` 世界观、渡口规矩、代价与六卷体系
- `03-cast-bible.md` 人物档案
- `04-relationship-map.md` 关系图
- `05-main-plotlines.md` 主线设计
- `06-foreshadow-ledger.md` 伏笔台账
- `07-chapter-roadmap.md` 章纲路线图
- `08-dynamic-state.md` 动态状态
- `09-style-guide.md` 风格指南
- `chapters/` 定稿正文
- `control-cards/` 每章控制卡
- `logs/` 写作日志，仅供审计
- `docs/` 研究底稿，不进入叙事真值

## 已定事项

- 题材：东方仙道志怪 / 悬疑
- 体量：约 200 万字，700 至 1000 章，章均 2500 至 3000 字
- 核心装置：渡口一盏灯对一人，灯灭一笔落，那人就过河
- 主角：陆守灯，渡口看灯人，名字由上代写进簿子，岁数从那年停住
- 代价：对生死的裁量权。他落笔的手比脑子先知道，力越长，他越不像普通渡夫
- 全书引擎：后屋坐着的爷爷，就是他将来的样子
- 开场切入：上游一处野渡
- 骨架：卷一至卷六沿一条水脉走，河道就是规矩
