## 一句话

三千年前，人族把十头大妖封进十座山。史书上写了九个名字，第十行是空的。今年斩妖节，青塘镇照例往锁妖井里投了一个祭品。祭品在井底睁开眼，自己爬上来，走回祭场，说：你们给的那一份，我收了。

## 硬规矩

1. 每一章至少做到两件：压一次场、收回自己一样东西或收一路旧部、杀一个人或翻一笔旧账。
2. 压场三段：先给对手一个讲得通的场面，他改规矩，三下以内收账。
3. 他强在三千年睁着眼，不强在力气。弱的段落要真弱，挨了要养。
4. 三千年前的事一次只揭一层，谁说的都带偏差。
5. 他不抒情，不解释，不变热血。人族的道理在他那儿过期了。
