# 09 风格指南

## 风格配置

- 主风格：东方修仙，爽文向
- 辅助风格：报仇、打脸、开宗立派
- 禁用：法宝对轰、境界数值表格、无理由越级、后宫、网络梗
- 平衡目标：打得响、脸打得脆、升级升得让人信

## 第一条硬规矩：每章动一次

每章至少做到两件：打一次脸、进一层修为或扩一分山门、结一段关系或翻一段旧账。

打脸要两段式。**先在道理上占住，再出手收账。**

1. 对手先立一个规矩，且这规矩摆在场面上站得住
2. 主角不动手，先用一句话或一件东西把规矩顶回去
3. 收账的时候才动手，动手只写三下以内
4. 赢完不停在主角身上。落在一个旁观者的反应上：谁手里的碗掉了，谁把话咽回去了，谁先叫了一声

## 打斗怎么写

一场打斗只写四件事：

1. 谁先动
2. 动哪儿
3. 疼在哪
4. 谁收得干净

短句，一句一个动作。不写招式名，除非人物自己喊。不写旁白点评这招漂亮不漂亮。

身体要有反应：挨刀的地方先是凉再是热；手抖，耳朵嗡，嘴里发苦。

### 不许出现

- 不许打一半被人叫停
- 不许平手收场
- 不许打完没事人一样。要留伤，留血，留一口喘不上来的气
- 不许越级赢得没理由。赢要赢在速度、地形、对方的伤、手里的东西、心上那一口气

## 系统怎么写

《山门录》是这本书的金手指，写法上有三条硬规矩：

1. **面板要短**。一次不超过四行。写清三样：进多少、够换什么、还差多少
2. **系统不说废话**。老翁只报数、只给规矩，不夸主角，不点评局势
3. **换来的东西必须用上**。换回来到兑现，最长不超过五章

## 情感怎么写

- 恨：不写他恨。写他把父留下的那半块匾贴身放着，三年没换过衣裳，怕磨了边
- 恩：不写他感恩。写他给铁牛留半个包子，自己啃硬的
- 义：不写兄弟情。写铁牛挨打的时候，江砚先动的手
- 爱：不写喜欢。写她把名册上那一行替他多留了半年

### 不许出现

- 不许人物自白心里感情
- 不许旁白替人物解释感情
- 不许用「心中一暖」「鼻子一酸」这类现成句

## 语言

- 短句为主。长句留给回忆和压在心里的东西
- 比喻的喻体只从眼前和身上取：水、石阶、扁担、灶灰、包子、血
- 一个名词加一个动词，比三个形容词重
- 对话格式：说话人加说或问，冒号，双引号
- 不写连续裸对话，一段里不超过三句对话
- 全章叹号不超过三个，省略号不超过一个
- 不写招式名、不写境界数值表、不写作者插话

## 视角与镜头

- 第三人称，贴着江砚走
- 只写江砚能看见、听见、摸到的
- 别人的心思写在他的动作上，不写旁白
- 不许旁白报告句。凡是「原来是这样」「这才知道」都删
- 反应落成动作：不写他愣住了，写他手里的扁担掉在地上

## 名字与叫法

- 江砚：旁白写「江砚」
- 陆铁牛：旁白写「铁牛」
- 沈姒：旁白写「沈姒」
- 老翁只叫「老翁」
- 山门匾一律写「匾」，孤山宗的匾写「孤山宗的匾」

## 每章交付前自检

1. 这一章打了谁的脸，推进了什么
2. 有没有账本式、数值堆砌的句子
3. 打斗有没有疼、有没有收刀
4. 系统面板是不是超过了四行
5. 章末最后一行是不是别人的话或一个正在发生的动作
6. 叹号、省略号
7. 有没有把该养伤的地方跳过去
