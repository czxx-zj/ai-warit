# 05 主线设计

## L1 自己的话自己不敢认（主线）

- 线类型：主线
- 核心冲突：谭正阳与体内那个东西争「这句话是谁说的」。他修为越高，越分不清
- 当前目标：活过立堂，弄清自己身上发生了什么
- 当前障碍：没有任何一方能给出可验证的解释
- 活跃人物：谭正阳、体内的东西
- 因果链：他早知道身上有东西，接堂报号，堂安不成，上道教求查，查不出名目。他每学一手，本事涨一分，那东西就离他心智近一分，代价累积
- 社会压力：亲友视他为病人或灾星，官方的疾病与事故归档
- 上次有效推进：待开写
- 热度：全书最高
- 回压：每一卷至少要他亲口说出一句自己不想说的话
- 下一转：他第一次主动让那东西上身，事后回想起自己的动作，都像是他要做的，可他说不出那个念头从哪儿起的
- 收束条件：他自己管这张堂单，自己定规矩；代价是他依然认不出自己的话
- 与其他线关系：所有线最终都汇入这条线

## L2 各门对那东西的叫法（暗线）

这条线不进前台，是他路上一件件捡起来的。前台永远是眼前的事，捡说法是事后才回过味来。

- 线类型：暗线
- 核心冲突：他身上的东西没有名字。他走过的每个地方，各门都给它一个叫法，没有两个对得上
- 当前目标：他没打算收集。是每到一个地方，都有人指着他说，你身上那个我们这儿管它叫什么
- 当前障碍：前一个叫法刚听顺耳，下一个地方的说法就把它推翻了
- 活跃人物：马长海、白守义、四地的关键人物
- 因果链：出马叫它空碑，道教的规矩是把它从名册上划掉，萨满给出更古老的说法，后三地各补一个
- 社会压力：两家不认对方的说法。后几地各说各的，谁也不管谁
- 上次有效推进：待开写
- 热度：低，慢烧。每卷只在收束处露一次头
- 回压：每多一个叫法，前一个解释就少站得住一点，可没有一个说得出它到底叫什么
- 下一转：他发现这六个叫法说的是同一个东西，而那东西其实没有名字
- 收束条件：他给它一个说法。那是第七个，是他自己给的
- 与其他线关系：为 L1 供料，答案落在 L3

## L3 家族亏欠（暗线）

- 线类型：隐藏线
- 核心冲突：祖辈做过的事，代价为什么由谭正阳来还
- 承担功能：全书泪点主场。四个泪点（第 82、100、118、124 章）全部落在这条线上
- 当前目标：查清奶奶的身份与当年那堂为什么没立完
- 当前障碍：活着的长辈用沉默保护他，也封锁他
- 活跃人物：谭玉兰、刘桂芝（遗物与回忆）
- 因果链：奶奶是守堂人，堂口未交完，漏洞落在血缘最近的人身上
- 社会压力：闯关东家族史与单位制解体后的人情债
- 上次有效推进：第一章，旧碗筷与柜子最上层已埋
- 热度：中，全书埋线
- 回压：每卷揭一层，就毁掉谭正阳对家的一段信任
- 下一转：他在族谱上查出一个多余的名字，那不是他家的人
- 收束条件：他明白奶奶当年拿一个外人的名字顶过那一格，这笔账落在血缘最近的人身上
- 与其他线关系：L2 的答案藏在 L3 里

## L4 两家的旧账（侧线，卷一至卷二为主）

出马和道教是两套正经规矩。这两家互不认，谁也说服不了谁，最后只能按各家的规矩办他。

- 线类型：侧线
- 核心冲突：两边都要管他，管的不是同一样东西。出马管的是他这个弟马，要护住这一堂；道教管的是他身上那个东西，无名无册，按规矩不能留
- 当前目标：出马要他留在堂口里受规矩，道教要他先把身上的东西处理掉
- 当前障碍：他两边都站得住，所以两边都不肯让他走
- 活跃人物：马长海、白守义、道观的老道长
- 因果链：那东西查不出名目，道教只能照规矩办，出马不肯让人在自己地界上动手，谈不拢就按各家的规矩来
- 社会压力：民间权威无仲裁机制，面子就是地盘，丢了面子就断了香火
- 上次有效推进：待开写
- 热度：卷一至卷二为主，卷三后转成余账
- 回压：每卷至少一次因两家的旧账，导致无辜者受损
- 下一转：两家头一回联手，只为一起处理他
- 收束条件：两家最后都认他这张单子
- 与其他线关系：制造外部压力，保证 L1 不被写成独角戏

## L5 分卷本地单元（侧线，每卷独立）

- 线类型：侧线
- 核心冲突：本卷地域自成一套空间规则，规则差异本身就是恐怖来源
- 当前目标：在本卷规则下解决一个本地事件
- 当前障碍：本卷规则与主角已有认知冲突
- 活跃人物：本卷关键人物与本地居民
- 因果链：本地事件解决完，那东西在这儿被人叫的名字也就露出来了
- 社会压力：本地生计、禁忌、宗族关系
- 上次有效推进：第一章，写实表层与丧事流程已建立
- 热度：每卷独立拉满
- 回压：本地事件的代价会留到下一卷
- 下一转：本地解法在下一卷失效
- 收束条件：本卷规则被主角部分掌握
- 与其他线关系：给 L2 添一个名字，给 L3 添一块拼图

## L6 斗法与地盘（侧线，贯穿）

- 线类型：侧线
- 核心冲突：谁说了算，没有一方有仲裁权。卷一至卷二是出马与道教两家争，卷三起是他撞进别人地界，本地人说了算
- 承担功能：全书打斗主场。卷一十场打斗（口舌五、法事三、上身对撞二）全在这条线上，卷三至卷六每道关卡另有摩擦与斗法
- 当前目标：谭正阳在别人的地界上活下来，并且不被任何一方收编
- 当前障碍：他的字号码头，出了自家那条街就不硬。到了生地方，先得拿本事换一个说话的位置
- 活跃人物：马长海、白守义、各卷地的关键人物
- 因果链：名头顶不住就动手，动手就有人受损，受损就多一笔账
- 社会压力：民间权威没有仲裁机制，面子就是地盘，丢了面子就断了香火
- 上次有效推进：待开写
- 热度：高，负责卷内大场面
- 回压：他每赢一场就多欠一笔账，账最后落在身边人身上
- 下一转：他第一次把两家不许混的法子并着用
- 收束条件：他立起自己的规矩，谁想进这个门，得按他的单子报号
- 与其他线关系：为 L1 提供代价，为 L4 提供爆发口

## L7 苗疆（情感副线，卷四主场）

- 线类型：侧线
- 核心冲突：两个人都被别人的规矩按住了名字，撞在一起
- 当前目标：他想在一块不属于自己的地方，留住一个不属于她自己的人
- 当前障碍：寨规不和外族通婚。这条规矩有实在的道理，不是谁有恶意，所以两个人谁也破不了
- 活跃人物：阿朵、谭正阳、龙阿公、石岩、麻老五、坡上的人
- 因果链：他身子自己找食，被引到苗疆；白苗黑苗之争逼他与白苗并肩；并肩生出情；情撞上寨规；寨规背后是祖蛊换主，破了就是全寨的命
- 社会压力：全寨的存亡压在一条婚规上。规矩吃人，也护人
- 上次有效推进：待开写
- 热度：卷四拉满，其余卷留余味
- 回压：卷五卷六各留一次回响。他每听见一次「圣女」这个称呼，就得想起他没留住的那个人
- 下一转：她当着他的面，第一次把自己的本名说出口
- 收束条件：不是在一起。是他把她的名字记住，而这个名字谁也收不走
- 与其他线关系：L3 写的是家里替他定名，L7 写的是规矩替她定名。两条线是同一台机器的两个零件，L7 让 L1 的中心问题第一次落到第二个人身上

### 这条线为什么不是言情主线

全书的中心问题是他自己说出来的话、做下的事算不算他的。苗寨这一趟，是这个问题最锋利的一次发作：他要留下来，得先把谭正阳交出去；她要留下来，得先把本名交出去。所以它给 L1 供血，自己不成主线。卷四写完，这条线转冷留余味，不占后两卷篇幅。

## 关卡结构

卷三至卷六各是一道关卡，走同一套四段：撞上、摩擦、一起办事、认还是不认。四卷四个结果：卷三认，卷四情，卷五毁，卷六价。

关卡不是换地图，是换一套吃人的规矩。他每进一道关，名头先失灵，再挨一顿，再靠本事站住，最后被这一门收一次账。
