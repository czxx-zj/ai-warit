# 第 81 章 回关

进关那天，下雪。

雪不大，落在关墙上，一层薄白。街上的人比平时少，铺子开着门，门口挂着帘子。

江棠在酒铺后头温酒。

听见帘子响，她抬头。

「回来了。」

「回来了。」

她看见江砚身后跟着沈梧，看见沈梧背上背着一把剑，看见江砚的脸色。

她把刀放下。

「他呢。」

「在。」

江棠站着，两只手在围裙上按了一下。

她没有再问。

她走到灶前，把火拨旺，添了一瓢水。水开了，她下面。三碗。

面端上来，她自己那碗没动。她坐在边上，看江砚吃。

吃完，江砚把事情说了。

从剑坑说到井底，从骨说到天界，从三个条件说到那个跑了的白袍人。

他说得很慢。

江棠听完，站起来，把三只碗收了。

她洗碗洗得很慢。水凉了，她没添热的。

洗到第三只，她停了一下。

「他左边那条胳膊，」她说，「能抬起来吗。」

「能。」

「那他为什么不回头。」

「他一回头，口子就开。」

江棠把那只碗搁在灶台上。

她拿布擦了擦手，走到里屋，从柜子最底下拖出一个包袱。包袱打开，是一双鞋。新鞋，黑布面，千层底。鞋底上纳的线，一道一道，很密。

她把鞋摆在炕沿上，摆得整整齐齐。

「这双，」她说，「我十六岁做的。」

「给谁的。」

「给你。」江棠说，「你那年十四。我想等你十六再给你。你十四那年，我掉下去了。」

江砚看着那双鞋。

鞋面上一处没纳匀的地方，线歪出去半分，又被她绕回来了。

「你穿上。」江棠说，「你那双都露脚趾了。」
