# 第 97 章 门主

骨上第九位那一处，亮了。

不是青光。是白的。

白光顺着骨爬了一圈，爬到骨尾，停住。

名卷展开在江砚膝上，布自己翻过来一段。

「阵认了。」沈梧说。

江砚往坑底看。

「爹。」

底下没有回话。

「江鹤。」

还是没有。

江砚站起来，往坑边去。郝三一把抓住他胳膊。

「你别下。」

「他不出声了。」

「他三年不出声的时候多了。」

江砚挣了一下，没挣开。郝三的手是死的，抓人像抓东西。

底下有声音了。

很轻。

「你写错了。」

是江鹤。

「没错。」江砚说。

「你写的是你。」

「写的是我。」

「我在这儿坐了三年，」江鹤说，「阵认我。你写你，阵就认你。你下来，我上去，你坐这儿。」

「你上去。」

「我十七年藏你，」江鹤说，「藏出这么个犟种。」

他笑了。

江砚听见底下有铁索响。

那不是爬的声音。那是用手抓铁索、抓一下滑一下的声音。

江鹤没有指甲。

他往上爬，爬了半宿。

天快亮的时候，一只手从坑沿底下伸上来。

上头没有肉。骨头外头包着一层干皮。

江砚伸手去拉。

江鹤说：「别拉手。」

「为什么。」

「手没了。」

江砚去抓他胳膊。

把他拖上来的时候，江砚先看见的是背。

背上有一排钉眼。钉子拔了，洞还在，洞边是白的。

江鹤整个人缩着，像晒干的柴。头发全白，脸上褶子深得能夹住沙子。

只有眼睛是活的。

他站起来，站不直。他扶着坑边的石头，先看坡上。

坡上那六个人还站着。

江鹤看了他们一会儿，转过头来。

「你姐呢。」

「关下。」

「活着。」

「活着。」

江鹤点了一下头。

他扶着石头喘气。喘了十来下，才把气顺过来。

「那就好。」

天边亮了一条线。

坡上那六个人的白袍忽然一齐往一个方向摆。

不是风。

他们都在看天上。

江砚仰头。

天上有个人下来了。不着地，离地三尺，白袍，袖口有一道灰线。

是尹。

他落下的时候，坡上那六个白袍一齐低了低头。

尹落到阵前，没看江砚。他先看江鹤。

「你还活着。」他说。

江鹤没理他。

尹这才转过来，看着江砚膝上的骨。

「名字写上了，」他说，「门有主了。好。」

江砚把骨往怀里收。

尹看着他收，没有拦。

「我三天前说的话，你听进去了。」尹说，「念完了，门有主。门有主，我才好收。」

「我不给。」

「你给不给，」尹说，「不是你的事。」

江鹤忽然开口。

「你收骨，」他说，「收的是名字。」

尹看他。

「名字在人身上，」江鹤说，「你收骨，就得收人。三百个名字，你收得完吗。」

尹没有答。

他往后退了一步。

他身后那六个人往前一步。
