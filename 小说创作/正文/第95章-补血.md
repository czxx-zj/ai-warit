# 第 95 章 补血

江砚补了三天。

布卷摊在膝上，石头搁在旁边。他拿刀在左手掌上横着划开一道，把手压在石头上第一道血印上。

血印吃血。

吃进去，那道旧印红了一点，从印里头往外亮。亮到一半，石头上立起来一个人。

那人很淡。看不清脸，也看不清穿的什么。他站在石头上，转过身，往坑底走。

走到断石那儿，他下去了。

底下响了一声。像是有人踩在空的地方，踩实了。

江砚把手抬起来，看那道印。印是红的，实了。

他划第二刀。

沈梧站在扇面上，郝三守着水，柯岩攥着那两块石头。

第一天，他补到一道上，停了一下。

那道旁边刻着两个字，是常伯刻的。沈梧念给他听：崔六。

崔六是屯里的老猎户。嘴大，胆小。江砚小时候跟他上山，他教江砚认脚印。

「崔六。」江砚说了一声。

石头立起来一个人。

那个人比别的高一点，走的时候肩膀一晃一晃。他往坑底走了七步，走到第八步，回头看了一眼。

看的不是江砚。他看的是坡上头。

坡上什么也没有。

他下去了。

第二天，他补到另一道。

补完，他往坡上看了一眼。

坡上那队人还站着。赵石头在队伍里，低着头。

他没抬头。

石头上又立起来一个，往坑底走。

第三天后晌，布卷只剩最末一段。

江砚的手不抖。他抖的是别的地方。他坐得很直，左手摊在膝上，掌心那一道已经划烂了，划成了三横一竖。

血出来得慢。

他把手按上石头，等。

等血把印填满，他才抬起来，补下一道。

郝三把水递过去。他喝一口，接着补。

补到倒数第二道，他停住。

「怎么了。」沈梧问。

「这一道，」江砚说，「是端木。」

「端木长老是第九位。」

「他是让位的那个人。」江砚说，「他让了。」

沈梧蹲下来。

「布上是他，」他说，「可阵里是他吗。」

「不是。」

「阵里是我爹。」

沈梧没有说话。

「布上是谁，」江砚说，「阵里就认谁。」

「那补下去。」

「补下去，」江砚说，「阵认的是端木。端木已经没了。认一个没了的人，门就撑不住。」

沈梧抬起头来。

「那要补谁。」

「补真的。」江砚说。
