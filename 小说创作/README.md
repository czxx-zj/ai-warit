# 重开山门

东方修仙。金手指加开宗立派，主线报仇打脸、一路升级。

旧稿《榜上无名》整套封存于 `archive/榜上无名-旧稿/`，《守灯》封存于 `archive/守灯-旧稿/`，一份未删。

## 一句话

孤山宗一夜被灭，少主江砚没死，隐姓埋名在仇家山门里挑了三年水。他要拿回被缴去当废料的那块山门匾。匾抢回来的当夜，匾里那本《山门录》认了他。从今往后，他每为孤山宗挣回一分，这本录子就还他一分。

## 硬规矩

1. 每一章至少做到两件：打一次脸、进一层修为或扩一分山门、结一段关系或翻一段旧账。三件都不占的章，删掉。
2. 打脸两段式：先占住道理，再出手收账。收账只写三下以内。
3. 打斗落到实处：谁先动，动哪儿，疼在哪，谁收得干净。不许平手，不许打一半被叫停。
4. 人物心意写成动作，不许自白、不许旁白解释。
5. 系统面板一次不超过四行，换来的东西不许闲置超过五章。
