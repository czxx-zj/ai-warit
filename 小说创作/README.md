# 碑上无名

东方玄幻武侠。一本由爱恨情仇直接推动的长篇。

旧稿《守灯》整批封存于 `archive/守灯-旧稿/`，一份未删。新书另立。

## 一句话

一个给山门刻碑的人家被灭门，唯一的活口被仇人养大，学会了仇人的刀。他的本名从碑上被刮掉，他要一个一个找回来，最后找到立碑的那个人。

## 硬规矩

1. 每一章的推进力必须是一段关系的变化，或一次出手。两者都没有的章不许写。
2. 不写账本、不写计数、不写代价机制、不写条文与实际两层。规矩只是人物嘴上的一句话。
3. 打斗落到实处：谁先动，动哪儿，疼在哪，收得干净不干净。
