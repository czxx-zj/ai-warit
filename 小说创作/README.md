# 小说项目

本项目使用 `novel-control-station` 作为长篇控制中枢。项目根目录即控制面。

## 文件系统

- `00-project-overview.md` 项目总览与核心承诺
- `01-theme-and-proposition.md` 主题与命题
- `02-worldbuilding.md` 世界观、六路体系、规则与代价
- `03-cast-bible.md` 人物档案
- `04-relationship-map.md` 关系图
- `05-main-plotlines.md` 主线设计
- `06-foreshadow-ledger.md` 伏笔台账
- `07-chapter-roadmap.md` 章纲路线图
- `08-dynamic-state.md` 动态状态
- `09-style-guide.md` 风格指南
- `chapters/` 定稿正文
- `control-cards/` 每章控制卡
- `logs/` 写作日志，仅供审计
- `docs/` 研究底稿，不进入叙事真值

## 已定事项

- 题材：中式微恐 + 克苏鲁，民俗诡异向
- 体量：约 200 万字，700 至 1000 章
- 六路体系：道教、出马、萨满、巫蛊、傩戏、占星
- 主角被上身这件事挑不了，但信谁、学哪套、认哪门规矩，他能挑
- 核心实体无名无相，它一路被人叫过的名字都是痕迹，痕迹可命名、可研究、可对抗
- 开场切入：东北出马
- 骨架：萨满为骨，出马为经络
