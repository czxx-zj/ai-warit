# 第 1 章 多摆一个（试写）

姑姑打来电话，只说了一句：“你奶奶走了。”

我问哪天走的。姑姑说：“你回来就知道了。”

我又问走的时候身边有没有人。姑姑还是那句：“你回来就知道了。”

街坊谁家办白事，都来请姑姑张罗。哪家老人什么时候走的、席上该摆几双筷子，她张口就报得出，从没差过。这回是自家的事，她一个字不肯先说。

火车到站是后半夜，雪粒子横着打。小城就一条主街，从站前通到铁道那头。楼是厂子当年分的，六层，没电梯，楼道里的声控灯坏了一半。

我到的时候，楼下的灵棚已经支起来了。

白布棚子四面透风，里头一张桌子、两个花圈、一盏长明灯。火苗缩在玻璃罩里，风一过就歪。雪落地化成水，顺着棚顶往下滴。有人路过，朝棚里扫一眼，认出是白事，脚下就快了。

棚口站着个老太太，朝长明灯拜了一下，没进屋，转身走了。

我在棚口站了会儿。桌子上摆着灵位，白纸黑字，写的是奶奶的名字。灵位上压着一张照片，放大了，印得发灰，我在屋里的墙上见过同样一张。长明灯的灯芯烧得低，罩子里积了一层烟。我伸手想把灯罩扶正，手到半空，又收回来。

楼道口的台阶起了冰。我拎着箱子上楼，鞋底一滑，薅住那根锈死的铁扶手才站稳。整栋楼都是煤味，混着谁家炖白菜的气味，还有一股香灰味，从三楼那扇开着的门里飘出来。

门里人声嘈杂，电视开着。姑姑站在客厅中间，手里捏着一张单子，指挥两个人把折叠桌往墙边挪。

姑姑说：“再往里。人一会儿都来了，没地方站。”

我叫了声姑，又问有什么要我办的。

姑姑说：“小阳，你把你箱子搁你奶奶屋，别搁门口。”

我站着没动，又问明天的事怎么安排。

姑姑说：“都写单子上了，你不用管。”

我应了一声，拖着箱子往里走。

屋子不大。客厅摆开一张折叠桌，再挤进四个花圈，人一多就得贴着墙站。最里头那间屋门虚掩着，那是奶奶住的屋。

我推门进去。屋里比客厅冷。床头柜上摆着七八个药瓶，旁边一个搪瓷缸子，水面上冻了一层薄冰。窗台上有个温度计，红柱子停在十六度。我把箱子搁墙根，没往床上坐。

床上的被子叠得整整齐齐，被角压平了。床底下摆着一双棉拖鞋，鞋尖朝里。墙上钉着一张黑白照片，是奶奶年轻时候的样子，梳两条辫子，穿一件洗得发白的对襟褂子，肩膀挺得很直。照片边角卷起来，用图钉按着，旁边留着几个旧的钉眼。

床头挂着一本旧日历，纸页发黄。我翻了一下，每一天下面都有一道铅笔道。划到上个月十三号就断了，最后那一道划得很轻，像划到一半停了手。

客厅里有人喊我。我出去跟着搬了几趟凳子。

来的人不多，我认得一半，剩下的要姑姑介绍。沙发角上坐着个老头，一直没说话，手边杵着一根拐杖。

姑姑说：“这是你奶奶的老同事，姓王。”

我伸手过去。王大爷握住，握了一下就松开，手是凉的。他看着我，嘴动了一下。

最后王大爷什么也没说。

后面又来了两个邻居，都是老太太。她们进门先在遗像前站一站，鞠三个躬，再坐到沙发上跟姑姑说话。声音压得很低，我只听清几个词，出马，老刘，该来的。等我走过去，话就停了。一个老太太打量我两眼，问我：“你奶奶走之前，跟你交代过什么没有？”

我说：“没有。”

老太太说：“那行。”

没有人提奶奶的名字。他们说得最多的是天气和路况，好像只要把话说满，屋里就没有空出来的地方。

有个表舅在客厅里转了两圈，转到我跟前站住，问这房本上写的是谁的名字。

姑姑在厨房门口听见了，说：“今天不看这个。”

表舅说：“我就是问问。人都在，问一句怎么了？”

姑姑说：“问问也别在今天。”

表舅把杯子往茶几上一墩，没坐，看着我。

表舅说：“正阳，你在省城待惯了，这房子你还要不要？”

我停了停。开口之前，我先认了认这句话是不是我自己要说的。认清了，我说：“要。”

表舅愣了一下。

我说：“本上写的我奶的名。她的名还在，谁也别急着动。”

表舅说：“我不是那个意思。”

我说：“那你是什么意思。等我奶出了殡，你把这句再问一遍，我接着答。”

屋里没人说话。有人低头咳了一声，扭头把话岔到雪上，说这雪要下到后天。王大爷坐在沙发角上，拐杖往地上顿了一下。姑姑端着菜从厨房出来，看了我一眼。那一眼我认得，是在掂量我。

表舅端起杯子喝水，没再开口。

我上一次回这栋楼，是三年前的中秋。那次奶奶让我多住两天，我说单位忙，第二天一早就走了。走的时候奶奶站在楼下，一直看到我上车。

我进门到现在，没有一个人跟我说过奶奶是怎么走的。哪一天，什么病，走的时候身边有没有人。我也没敢问。我怕一开口，下一句就是问我这三年怎么没回来。

单位忙。

这三个字，我拿它挡了三年。

天黑透了，人才算到齐。

姑姑在厨房下了一锅面，让我摆碗。我从吊柜里捧出一摞碗，挑干净的往外拿，一只一只往桌上放。

放一只，看一眼桌上的人。

屋里连我七个人。我数过两遍。七个人，七个碗。

摆完最后一只，我退后半步看了看。七个碗一圈摆开，靠墙那一侧空着一个位置，正对着客厅另一头的供桌。

姑姑端着锅出来，看了一眼桌子。

姑姑说：“多摆一个。”

我说：“人齐了。”

姑姑把锅往桌上一墩，锅底磕着桌面，响了一声：“我知道人齐了。多摆一个。”

我没问。我从摞里又拿了一只碗，摆在靠墙那边。姑姑看了一眼那个位置，走过来，把碗端走了。

姑姑端着碗走到客厅另一头。那边有张供桌，桌上摆着奶奶的遗像、一个香炉、两盘供果。遗像是前几年照的，头发还没全白，嘴角抿着。两个苹果一个橘子，摆得很齐。桌面干净，像是天天有人擦。

姑姑把碗放下，又打开旁边那个老柜子，从最上层摸出一样东西。

我先闻到一股樟脑味，跟着是瓷碰瓷的一声轻响。

是一副旧碗筷。

碗沿豁了一个口，筷子颜色发深。姑姑把碗筷摆在遗像正前面，摆得很正，碗口冲着门。

我站在厨房门口看着，问：“那是给谁的？”

姑姑没回头，说：“给看家的。”

我还想再问。姑姑已经转身进了厨房，掀开锅盖，喊人吃饭。

那顿饭吃得很快。没人说话，筷子碰碗沿的声音很清楚。有人说了句天气预报，说明天还有雪。

姑姑应了一声：“嗯。”

电视一直开着，没人换台。

王大爷一直没动筷子。别人吃，他就坐着，手搭在拐杖上，眼睛看着供桌那边，看了很久。久到我也跟着看过去。供桌上除了那副碗筷，什么也没有。

我小时候见过一次，也是这么摆着，碗口冲着门。那是爷爷走的第二年，家里闹过一阵子事。什么事我记不清，只记得那几天奶奶不许我往供桌前凑，也不许我问。那副碗筷摆了三天，三天之后，奶奶把它收进了柜子最上层。

柜子最上层。姑姑今天把它拿下来了。

吃完饭，人陆续走。姑姑在门口送客，说一句，客人回一句。我把碗摞起来，一趟一趟端进厨房。

再出来，客厅里只剩姑姑。桌子收了，椅子摆回墙边。

我走到供桌跟前。香炉是空的。

奶奶活着的时候，碗摆上，香就得跟上，一天都不能断。今天碗早摆上了，香没点。

我走到厨房门口，问：“姑，怎么不点香？”

姑姑正在刷锅，手没停，说：“等人齐了再点。”

厨房里的水龙头还开着，水冲着锅底，哗哗地响。我站在那儿，这声音一下挤进来，近得不像是隔着一道门。

姑姑刷完锅，擦手出来，站在供桌前，看着那副碗筷。灯是四十瓦的，照得那副碗筷发黄。碗口冲着门，香炉空着。

我伸手碰了一下香炉，炉壁是凉的。

饭前我说人齐了，姑姑说，多摆一个。

这会儿人都走净了，她还是那句，等人齐了再点。

我不知道她还等谁。
